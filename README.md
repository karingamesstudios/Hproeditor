# Hproeditor

**Editor visual de páginas web**

Hproeditor es un proyecto de editor visual web que busca facilitar la creación y personalización de páginas HTML mediante una interfaz gráfica intuitiva, reduciendo la necesidad de escribir código manualmente.

El objetivo es ofrecer una herramienta flexible para diseñar páginas web, organizar elementos visuales y crear proyectos adaptables a distintos dispositivos.

## ✨ Características y objetivos

- 🎨 **Edición visual:** diseñar páginas mediante una interfaz gráfica.
- 🧩 **Personalización de elementos:** modificar textos, imágenes, fondos, tamaños y otros estilos.
- 📱 **Diseño responsive:** crear páginas que se adapten a computadores, tabletas y celulares.
- 👁️ **Vista previa:** visualizar los cambios durante la edición.
- 📄 **Exportación HTML:** objetivo de generar páginas web que puedan abrirse en navegadores.
- 🗂️ **Gestión de proyectos:** organizar y continuar trabajando en los diseños.
- 🛠️ **Herramientas de diseño:** facilitar la organización, posición y apariencia de los elementos.

*Las características están sujetas al estado actual del desarrollo.*

## 🎯 Objetivo del proyecto

Hproeditor busca hacer que el diseño web sea más accesible, permitiendo que tanto principiantes como usuarios con experiencia puedan crear páginas personalizadas mediante herramientas visuales.

El proyecto se encuentra en desarrollo y puede incorporar nuevas funciones, mejoras y cambios en su interfaz.
